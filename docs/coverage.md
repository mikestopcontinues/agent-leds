# Coverage

Generated by `coverage::render` from the table in `src/fsm.rs` and the signals each harness declares; `UPDATE_COVERAGE=1 cargo test` rewrites it.

## The table

Each cell is the phase the signal moves to; `·` means no rule, so the signal changes nothing, and `back` is back to the phase the session entered its row's phase from. A cell that names its own row's phase holds the session there against the signals ranked after it; alone it changes nothing, but a turn that ends again is announced again.

Columns: Start (Started), Prompt (Prompted), Perm (PermissionAsked), Quest (QuestionAsked), Answ (Answered), Rel (Released), End (TurnEnded), End? (TurnEndedAsking), Fail (TurnFailed), Intr (Interrupted), Bg (Backgrounded), BgDone (BackgroundDone), Ended (Ended), Look (Looked), RdExp (ReadExpired), Aband (Abandoned), Dism (Dismissed).

One record can tell several signals, each a fact of its own. The first of them in this order with a rule from the session's phase is the move: Ended, Interrupted, TurnFailed, PermissionAsked, QuestionAsked, Answered, Released, TurnEndedAsking, Backgrounded, BackgroundDone, TurnEnded, Prompted, Started, Dismissed, Abandoned, ReadExpired, Looked.

Signals of one family are told together by sound sessions:

- TurnEnded, TurnEndedAsking, Backgrounded, TurnFailed, Interrupted
- Prompted, PermissionAsked, QuestionAsked

Any other signals told together overlap: the order above still decides, and the daemon counts each set in `agent-leds status --json` and `agent-leds doctor`.

## Moves each harness cannot make

**PermissionAsked**: an approval wait shows as the light it interrupts.

- Grok, for a tool's approval card
- Cursor: Idle, Working, Asked, Stopped, Failed → Blocked
- Pi: Idle, Working, Asked, Stopped, Failed → Blocked

**QuestionAsked**: a question the agent waits on shows as the light it interrupts.

- Cursor: Idle, Working, Asked, Stopped, Failed → Blocked

**Released**: a wait answered with no turn running shows as a question until the session moves on.

- Codex: Blocked → back to where it was found
- Grok: Blocked → back to where it was found
- Junie: Blocked → back to where it was found
- OpenCode: Blocked → back to where it was found
- Pi: Blocked → back to where it was found

**Backgrounded**: a turn whose background work runs on shows as stopped while that work runs.

- Grok, for a background command left running, which wakes the session with a turn of its own when it finishes; nothing at its start says whether it ever will, as a dev server never does
- Cursor: Idle, Working, Stopped → Background
- Junie: Idle, Working, Stopped → Background
- OpenCode, for a shell moved to the background, which wakes the session with a run of its own when it finishes; nothing says whether it ever will, as a dev server never does
- Pi: Idle, Working, Stopped → Background

**BackgroundDone**: background work that finishes is never announced, and shows as working until the next turn.

- OpenCode: Background → Stopped

**Looked**: looking at a session never marks it read.

- Claude Code, for a session run in a terminal, which the desktop app keeps no file for
- Codex: Stopped → StoppedRead
- Codex: Asked → AskedRead
- Grok: Stopped → StoppedRead
- Grok: Asked → AskedRead
- Cursor: Stopped → StoppedRead
- Cursor: Asked → AskedRead
- Junie: Stopped → StoppedRead
- Junie: Asked → AskedRead
- OpenCode, for a 1.x session, whose rows record no viewing, or a 2.x session no terminal interface shows, as one `opencode run` or another client runs through the service
- Pi: Stopped → StoppedRead
- Pi: Asked → AskedRead

## Phases never entered

Searched from `Gone` over the signals a harness declares and those the daemon tells of every session.

- Codex: AskedRead, StoppedRead
- Grok: AskedRead, StoppedRead
- Cursor: Background, Blocked, AskedRead, StoppedRead
- Junie: Background, AskedRead, StoppedRead

## Stuck phases

Phases with a light that a harness reaches but leaves only when its process ends or through the daemon's own signals, and phases reading settles that a harness never marks read, which keep their light until the session moves on, ends, or is dismissed or abandoned. Each is a place where an experiment or a deliberate guess is worth considering.

- Claude Code, Asked: never read, for a session run in a terminal, which the desktop app keeps no file for
- Claude Code, Stopped: never read, for a session run in a terminal, which the desktop app keeps no file for
- Codex, Asked: never read
- Codex, Stopped: never read
- Grok, Asked: never read
- Grok, Stopped: never read
- Cursor, Asked: never read
- Cursor, Stopped: never read
- Junie, Asked: never read
- Junie, Stopped: never read
- OpenCode, Asked: never read, for a 1.x session, whose rows record no viewing, or a 2.x session no terminal interface shows, as one `opencode run` or another client runs through the service
- OpenCode, Stopped: never read, for a 1.x session, whose rows record no viewing, or a 2.x session no terminal interface shows, as one `opencode run` or another client runs through the service
- Pi, Asked: never read
- Pi, Stopped: never read
